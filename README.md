# Sistema Pleno OAJ v1

Aplicación web para la gestión y visualización de información del Organismo Autónomo de Justicia (OAJ). Esta versión 1.0 representa la primera entrega estable del sistema.

## 🌐 Entornos

| Entorno | URL | Descripción |
|---------|-----|-------------|
| **Producción (main)** | [plenooaj.onrender.com](https://plenooaj.onrender.com) | Versión final estable, desplegada en Render. |
| **Desarrollo (dev)** | [cdelgadoffs.github.io/PlenoOAJ/](https://cdelgadoffs.github.io/PlenoOAJ/) | Versión de desarrollo alojada en GitHub Pages. |
| **Local (prev)** | `http://localhost:3000` | Entorno de preproducción, espejo local para pruebas. |
